# 接口与验证记录

## 学校接口

原程序于 2026-10-27 根据人工登录后的南信大教务页面适配。本次插件继续使用相同的只读查询：

| 相对 `/jwapp/sys/wdkb` 路径 | 用途 |
|---|---|
| `/modules/jshkcb/dqxnxq.do` | 当前学期 |
| `/modules/xskcb/cxxljc.do` | 学期开始日期和总周数 |
| `/modules/jshkcb/dqzc.do` | 指定日期的教学周和星期 |
| `/modules/xskcb/cxxszhxqkb.do` | 整学期理论与实验安排 |
| `/modules/jshkcb/jc.do` | 各小节作息时间 |
| `/modules/xskcb/xswpkc.do` | 未完整排入课表的课程 |

请求通过 WebVPN，会话限定学校域名。`SKZC` 按 0/1 位图筛选教学周；理论课使用学校作息，实验课优先使用课程自带时间。整学期查询不传单周参数，且拒绝分页截断的数据。正常接口内部 `extParams.code=1` 不视为登录失败。

## AstrBot 适配（2.0.0）

实现基于 AstrBot 公开的 `Star`、`StarTools.get_data_dir`、`filter.command`、`AstrMessageEvent.unified_msg_origin`、`MessageChain`、`Context.send_message` 与 `initialize` / `terminate` 生命周期；核对过上游源码，并确认 4.5.0 已提供所需插件数据目录接口。

本地测试包括：

- 理论/实验课程、单/双周、校历、调休、未排课、缓存过期、学期范围与网络异常。
- 登录助手的本机 Chromium 测试：原标签页恢复、Cookie 保留、课表模式切换、等待回车期间的浏览器事件处理。
- 每个私聊/群聊独立时间、无订阅时不查询、同批会话共用学校查询、后台线程读取。
- 当日即时查询不改变订阅或定时发送记录，修改时间替换旧任务，重复检查与重启去重。
- UTC 到北京时间的日期换算、午夜、已过时间从明日执行，以及停机后只补发当天。
- 取消订阅、取数期间取消、发送期间卸载、结果未知不重试、缺少平台时安全重试及日志脱敏。
- 插件入口的模拟接口集成：命令参数、会话绑定、先输出回复再停止事件传播、消息链发送、配置校验、后台任务单实例与卸载取消。

完整本地测试结果：**94 passed**；Python 编译检查、登录助手 wheel 构建及插件 ZIP 的文件校验通过。ZIP 采用公开文件白名单，不收录用户状态和配置；目录结构兼容 AstrBot 的上传解压方式。

## 2.0.1 依赖兼容修复

2.0.0 的 `filelock>=3.16,<4` 与 AstrBot 4.29.3 环境保护的 `filelock==4.2.4` 冲突。2.0.1 将运行依赖和登录助手包元数据统一改为 `filelock>=3.16`，使用宿主已安装的兼容版本。

验证结果：在本地实际安装 `filelock==4.2.4` 后，完整测试仍为 **94 passed**，`pip check` 通过；将 `filelock==4.2.4` 作为约束进行全新依赖解析（`pip install --dry-run --ignore-installed`）也通过。修复不要求调整 AstrBot 核心依赖；尚未在用户的 Linux AstrBot 实例中重新安装实测。

## 2.2.0 大模型工具与帮助指令

2026-10-29，新增四个 AstrBot 原生工具：`nuist_course_query`、`nuist_course_set_push_time`、`nuist_course_cancel_push`、`nuist_course_help`。查询返回结构化课表，由 AstrBot 的模型继续分析并生成回复；工具不会直接发送消息或停止事件传播。新增 `/帮助`，别名 `/课表帮助`，列出全部插件指令。

本次目录中的 `tests/test_llm.py` 实际运行结果为 **40 passed**，Python 编译检查通过。覆盖范围：

- 北京时间跨日的相对日期、指定日期和非法日期校验。
- 原始教室、同楼不同教室、缺失地点、理论/实验类型、未排课程、学校作息和既有文本输出。
- 指定日期、调休、停课、实时校历不一致、有效缓存、缓存缺失/过期/禁用和超出学期。
- 后台线程取数、查询不修改订阅或投递记录、登录恢复前释放文件锁、恢复失败后的缓存回退，以及文件锁冲突。
- 工具返回结构化 JSON、成功无课与查询失败的区别、保留 LLM 后续回复流程、按当前会话设置和取消推送、默认及非法时间、异常和日志脱敏。
- 帮助内容包含全部注册指令及别名，管理员私聊登录权限继续生效。

接口兼容核对使用 AstrBot **v4.5.0** 的公开源码。另以该版本实际的 `register_llm_tool` 函数配合真实 `docstring_parser`，对本版四个工具方法执行注册，全部通过；此项只模拟了工具注册表和事件元数据边界，没有启动完整 AstrBot。

本次测试没有访问真实学校账号、调用真实大模型或发送真实聊天消息。同楼结论由模型根据原始地点分析，测试验证了模型所需数据的完整返回，未验证某个具体模型的最终回答。部署后应启用支持工具调用的模型与这四个工具，发送自然语言查询和 `/帮助` 核对端到端行为。

## 验证边界

2.0.x 的测试使用模拟学校 HTTP 响应、模拟 AstrBot 上下文，以及本机浏览器页面。2.1.0 额外进行了上述真实学校登录与同步；未向真实聊天会话发送消息，也未部署或启动 AstrBot 实例。

部署时须验证学校会话能被 AstrBot 所在机器复用、平台支持主动消息，并在目标会话执行 `/查看课表` 和 `/设置时间 8`。会话长期寿命、跨 IP 限制和学校对节假日调休的录入情况仍取决于学校；真实聊天平台的长度限制及主动发送限制取决于适配器。
